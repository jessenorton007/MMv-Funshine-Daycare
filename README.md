# MMv Funshine Daycare

A custom, responsive website for Funshine Child Care & Learning Center LLC in Cedar City, Utah. Built locally with HTML, CSS, and JavaScript. No paid services, dependencies, tracking, or backend are required.

## Preview

Website preview: https://jessenorton007.github.io/MMv-Funshine-Daycare/

GitHub repository: https://github.com/jessenorton007/MMv-Funshine-Daycare

Run `npm start` and visit `http://127.0.0.1:4173`. The site also works on a normal static host: publish the contents of this directory. Use a static HTTP server for testing clipboard features.

## Included

- Preschool-first home page with program details and a keyboard-accessible activity switcher.
- Separate childcare section and nature-based learning overview.
- Responsive navigation, native FAQ accordions, and an accessible photo gallery dialog.
- Contact links, directions, and a validated tour inquiry form that opens the visitor's email app. Nothing is sent automatically; tours and enrollment are arranged directly with the center. A copyable inquiry is available as a fallback.
- Locally stored photos, supplied logo, and Google Fonts, so the page does not depend on third-party image or font requests.

## Content and assets

Business details and real center photographs were sourced from the supplied website: https://funshinechildcareu.wixsite.com/funshinechildcareccu . Preschool hours and childcare ages were updated from the business's October 2026 corrections: preschool runs 9 a.m.–12 p.m., and childcare welcomes children from 6 weeks to 12 years. Other contact information and program descriptions are based on the reference website. Prices and openings should be confirmed directly with the center.

The supplied Funshine logo is preserved in `assets/funshine-logo.png`. Photo filenames map to original Wix assets in `ASSET SOURCES.md`. Fredoka and DM Sans are distributed under the SIL Open Font License; see `assets/OFL-Fredoka.txt` and `assets/OFL-DM-Sans.txt`.

This is a new website design preview. The original Wix website has not been replaced. There is no Replit dependency, subscription integration, or automatic submission service. The preview includes a `noindex,nofollow` robots meta tag; remove it when the center approves its production launch. GitHub Pages serves the static project preview directly from the main branch.
